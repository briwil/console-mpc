# MACHINEDRUM

The Elektron Machinedrum's TRX, EFM, P-I and GND machines for Console, from
[OP-XY-MNMD](https://github.com/mmockett/OP-XY-MNMD) (MIT, `LICENSE-OP-XY-MNMD`), which wrote them from
scratch in fixed-point C++ for the OP-XY. No Elektron code, firmware or ROM data is here.

- `vendor/`: OP-XY-MNMD's `voices/` and `lib/` headers as they are, and three headers from the
  [Open-XY SDK](https://github.com/etcetc000/open-xy) (MIT, `LICENSE-OPEN-XY`) in `vendor/opxy/`.
- `md_catalog.h`, `md_dispatch.h`: generated by `vendor.py` from OP-XY-MNMD's catalog (the machines,
  their controls and defaults, the default kit). Run `vendor.py` again to update.
- `glue_md.cpp`: the 16 lanes and the C functions `drums.py` calls. `drums.py` (or `setup.sh`) builds it
  into `libmd.so`.
