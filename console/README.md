# Console's own code, as used on the MPC Sample

This folder is a copy of the Console app (the `pi-app` and `move` folders, the screen stubs, the licence) taken from
the Ableton Move version of Console at commit `bb3f0f2`. From here on it belongs to this repo: the card is built from
it, and nothing needs the Move repo any more. Changes made for the Sample go straight into these files (or into `mpcui/`,
which adds to the app without editing it). Fixes made in the Move version are not picked up automatically; bring them over by hand.

The prebuilt synths / drum machines / effects are not in git: they are the `libs-latest` release of this repo
(made by the "Import libs" workflow).
